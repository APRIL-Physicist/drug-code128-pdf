# Drug Code 128 PDF Tool

一个简单的原始 XML → Code 128 条形码 PDF 网页。面向不熟悉电脑操作的使用者：拖入 XML 后自动生成，点击按钮下载。

## 使用方法

1. 解压源文件，找到 `.xml` 文件。
2. 打开网页，拖入一个或多个 XML 文件，或者点击选择。
3. 生成完成后点击绿色下载按钮。单个文件得到 PDF；多个文件得到包含各 PDF 的 ZIP。

PDF 使用 A4 纸、窄页边距、两列排版，每列 10 个条码。条码为 **Code 128 C**，数字打印在条码下方。建议打印时选“实际大小 / 100%”，首次使用前用实际扫码设备核对一页。

## 数据与费用

文件仅在访问者的浏览器里解析，条码、PDF 和 ZIP 也在浏览器里生成。此项目不上传 XML，不调用 AI，不包含 API 密钥，因而没有模型 token 费用。

当前仅接受包含 `Data` 元素和 20 位数字 `Code` 属性的原始 XML。若文件名含“XX件”，还会核对 Code 数量。曾被电子表格作为数值保存的长数字可能丢失精度，因此不接受 XLSX。

## 部署

仓库根目录就是静态网站目录。将 `index.html`、`app.js`、`styles.css`、`favicon.svg` 与 `vendor/` 一同部署即可，无需构建和后端服务。

本项目使用的第三方浏览器库保存在 `vendor/`。其授权信息见相应文件和库文件顶部注释。
