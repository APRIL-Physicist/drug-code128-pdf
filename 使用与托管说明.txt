药品条码打印工具

给使用者：
1. 解压收到的原始文件压缩包，找到扩展名为 .xml 的文件。
2. 打开网页，把一个或多个 XML 文件拖进页面中；也可以点击“选择文件”。
3. 等页面出现绿色下载按钮后，点击保存。一个 XML 下载一份 PDF；多个 XML 下载一个包含多份 PDF 的压缩包。
4. PDF 按 A4 纸制作：窄页边距、双列，每列 10 个，一页最多 20 个。打印时选择“实际大小”或 100%，不要再缩放。

给网站管理者：
这是静态网页，无需服务器程序、DeepSeek API 或 API 密钥。条码与 PDF 都在访问者的浏览器本地生成，XML 不会上传到网站服务器。
本压缩包解压后可以直接双击 index.html 测试。上线时，把 index.html、app.js、styles.css、favicon.svg 和 vendor 文件夹一同上传到静态网站托管的根目录，不要只上传 index.html。
可选择腾讯云 CloudBase 静态网站托管：
https://cloud.tencent.com/document/product/876/46900
控制台支持上传本地代码包或文件夹，首页文件是 index.html。面向正式用户时，建议绑定自己的域名；具体备案要求按所选地域和服务核实。

网页仅接受 Code 为 20 位数字的原始 XML，并会核对文件名中的“件”数。遇到不符会显示提示，避免生成不可靠的条码。
